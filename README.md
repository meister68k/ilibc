# ilibc

ilibcは、OS・ファイルシステム・入出力・ヒープを持たない32bitマイコン向けに、C89標準ライブラリの一部をC++23で実装することを目指すフリースタンディングライブラリです。

## 特長

- 小さなマイコン環境を想定し、OS、I/O、ヒープ、浮動小数点に依存しません。
- C89標準ライブラリから、この環境で使う機能を選んで提供します。
- C++23で実装し、C++形式ヘッダを基本に設計しています。
- 動的メモリや外部状態への依存を避け、決定的な動作を目指します。
- 規格との意図的な違いや、提供しない機能を仕様書に明記しています。

## ilibcらしい独自仕様

標準ライブラリとの互換性を少し削ってでも、組込み環境で扱いやすくする工夫があります。

- **文字分類を安全側に**: `std::isalnum`など11個の分類関数は、標準の`int`戻り値ではなく`bool`を返します。また、標準Cで未定義動作となる範囲外の値を渡しても安全です。ASCII文字として分類できない値は`false`、`tolower`／`toupper`では値をそのまま返します。
- **バッファ容量を型から受け取る**: 書式出力の`ilibc::sprintf`は固定長配列を受け取り、容量を自動で把握します。容量不足なら`-1`を返し、配列の内容を変更しません。書式は`%d`、`%s`、`%%`に絞り、引数の個数や型をコンパイル時に検査します。
- **境界を見える形にする**: 整数変換には`errno`を使わず、エラー番号を書き込む引数を持つ`ilibc::`版もあります。エラー報告先に`nullptr`を渡せるため、必要なときだけ報告を受け取れます。
- **使わない機能は抱えない**: `malloc`／`free`、浮動小数点変換、`rand`／`srand`、`qsort`／`bsearch`、状態を持つ`strtok`、`setjmp`／`longjmp`などは提供しません。書式出力も幅・精度や浮動小数点変換を省き、コンパクトな範囲に限定しています。

このため、一般的なC/C++標準ライブラリの完全な代替ではありません。標準との差異や未提供機能は[リファレンスマニュアル](spec/ilibc_reference_manual.md)と各仕様書を確認してください。
